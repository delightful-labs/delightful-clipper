# Add Link and minimal saved reader

The application runtime owns one library actor for the current account binding after canonical-root readiness. The actor owns extraction, duplicate lookup, explicit-save preparation/publication, remote receipts, list subscription and reader loading. Presentation sends events and renders localized states. Sign-out, account replacement and shutdown invalidate visible content immediately, cancel read/network work, and drain issued local writes before releasing identity. Remote acceptance never blocks local availability or teardown.

URL identity is a conservative normalized final HTTP(S) URL without its fragment. Submitted URL, redirect observations and canonical candidate remain provenance. Canonical candidates do not merge articles. A library-scoped deterministic UUID identifies this destination; immutable publication and an existing-operation check prevent replacement and uncertain-write replay. A blocked/unknown operation offers reconciliation/Open, never an automatic second insert. Source metadata is atomically published with native text/HTML bytes under owner-only parent policies.

This batch exposes Add Link → preview → explicit save, a saved collection and a minimal text reader. Sanitized HTML is retained as native bytes for subsequent reader work; the minimal reader renders literal text and makes no remote image requests. Missing images are explicitly disclosed.
